Comment fonctionne une installation photovoltaïque ?

Les panneaux transforment la lumière du soleil en électricité. Cette énergie alimente en priorité votre logement, avant d'utiliser le réseau si nécessaire.

Autoconsommation et surplus

L'objectif est d'utiliser un maximum de l'énergie que vous produisez. Le surplus peut être géré selon la configuration retenue avec vous lors de l'étude.

Micro-onduleurs et monitoring

Selon le matériel choisi, chaque panneau peut être suivi individuellement. Un monitoring vous permet de visualiser votre production en temps réel.

Gestion intelligente de l'énergie

Connectée à la domotique SOLARIS, votre installation peut piloter automatiquement certains équipements selon l'énergie disponible.
